# 🚀 Mixed-Signal VLSI Design 

This repository documents my work on the physical design of a mixed-signal ASIC integrating an analog 2×1 MUX and a digital SPI controller. The implementation uses the SKY130 PDK and open-source EDA tools including OpenLane, OpenROAD, Magic, Netgen, and ngspice, covering the RTL-to-GDSII physical design flow, analog macro integration, floorplanning, placement, CTS, routing, DRC, LVS, and final layout generation.
